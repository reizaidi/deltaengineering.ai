# Delta AI Engineering website

Corporate website for Delta AI Engineering: a light "Delta Glass" interface (an original frosted-glass interpretation, not Apple's Liquid Glass assets), three interactive explainers, and a typed Connect RPC inquiry API.

The full research, recommendation, scorecards and evidence register are in [`docs/REPORT.md`](docs/REPORT.md) and [`docs/evidence-register.md`](docs/evidence-register.md).

## Run it

```bash
npm ci
cp .env.example .env.local     # fill in what you have
npm run dev                    # http://localhost:3000
```

Production build:

```bash
npm run build && npm start
```

## Checks

```bash
npm run check        # eslint + tsc + buf lint + unit tests
npm run test:e2e     # Playwright: navigation, keyboard, form + RPC, axe WCAG 2.2 AA, desktop + mobile
```

Run the e2e suite with `INQUIRY_DELIVERY=log` so the form succeeds without an email provider.

```

src/gen/                       Generated by `npm run proto:gen` (do not edit)
src/app/                       Routes: / services approach about contact privacy, api/[...connect]

src/machines/                  XState machines: inquiry form, Delta Method tour
src/components/motion/         HeroDelta, TradeoffTriangle, RetrievalDemo, DeltaMethod, Reveal

tests/unit, tests/e2e          Vitest and Playwright suites
```

## Inquiry delivery

The contact form calls `delta.v1.InquiryService/SubmitInquiry` over the Connect protocol at `/api`. Delivery uses Resend's HTTP API when `RESEND_API_KEY`, `INQUIRY_TO_EMAIL` and `INQUIRY_FROM_EMAIL` are set. In production without them, the API returns `unavailable` and the form shows the email address instead, so no inquiry is silently lost.

The rate limiter and idempotency cache are in memory (per instance). Move them to a shared store such as Upstash Redis or Cloudflare's rate-limiting binding before running more than one instance.

## Deploy

Vercel Pro or Cloudflare Workers (via the OpenNext adapter) both work; see the cost table in the report. Every page except `/api/*` is statically prerendered, and security headers (CSP, HSTS, frame-ancestors, nosniff, Referrer-Policy, Permissions-Policy) are set in `next.config.ts`.

Rollback: redeploy the previous build from the host's deployment history. There is no database, so there is nothing to migrate or back up beyond this repository and the environment variables.
